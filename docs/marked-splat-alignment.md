# Provisional placement from the retained human marks

The LAN pair contains the entire current reconstructed chunks: earlier
408.134389–412.230244 seconds (78 registered views), and later
414.562967–427.800311 seconds (235 registered views). The gap is 2.332723 seconds.
Neither section has an editor crop applied at this checkpoint. Selective moving
visitor masks were already used during reconstruction. These chunks do not
represent the entire 737-second recording.

The six retained choices are Q1→2, Q2→1, Q3→1, Q4→1, Q5→1 and Q6→4 in
[`human-choices.json`](../evidence/numbered-landmarks/human-choices.json).
Their pixels are transferred to the current undistorted reference views using
each section's original SIMPLE_RADIAL calibration. Alpha-compositing weights
provide a median Gaussian-center depth along each marked ray. This produces
approximate anchors, not measured surface points. The script retains all six
choices without outlier removal.

Three placements were compared, mapping later raw PLY coordinates into earlier
raw PLY coordinates:

| Candidate | Advantage | Observed limitation |
| --- | --- | --- |
| Marks only | Direct similarity fit to the six anchors | Estimated floors differ by 66.46 degrees |
| Coincident floor planes | Constrains both floor direction and elevation | Large anchor residuals, 2.31–3.81 arbitrary earlier-section units |
| Parallel floor directions, free translation | Useful visual starting arrangement near the marked region | Floors remain displaced by 3.28 arbitrary units; Q4 is inconsistent |

The third is the **provisional starting placement**, not a verified connection.
Its median anchor residual divided by median earlier anchor depth is 1.6%; that
is a fit diagnostic, not reconstruction accuracy. Scale is 1.06737 in raw PLY
coordinates. Floor samples also come from uncertain Gaussian-center depths;
parallel normals are imposed by the fit, not independently verified. All marks
cluster on one local region and do not independently constrain the whole room.

Inspection of the separate sections and combined render found a more intelligible
placement of the marked region, but tile edges and the floor do not join
convincingly. One splat can hide disagreement beneath another. Keep the section
toggles available and inspect both separately. Do not present this placement as
a recovered camera bridge, continuous floor, or forensic measurement.

## Reproduce

Use the same reference bundles prepared for the ghost inspector, containing
`earlier-references` and `later-references`, and the tracked PLY pair. NumPy and
Pillow are required. Output directories/files must be new to preserve receipts.

```sh
python3 scripts/align_splats_from_marks.py \
  --references /path/to/reference-bundles \
  --assets evidence/sam31-video-sections \
  --output /path/to/new-alignment-output
node scripts/marked_alignment_project.mjs \
  /path/to/exported-project.json \
  /path/to/new-alignment-output/fits.json \
  /path/to/new-candidate-project.json
```

The first command records input hashes, mapped marks, depth diagnostics, floor
fits and all three candidates. The second preserves the reference section and
all scene settings, changing only the later section's transform. It accounts
for the editor's 180-degree Z child rotation and checks matrix decomposition.
Neither script writes to the live editor or changes PLY assets. Back up the
current placement, import the candidate and Save. An automated application must
use the editor API's current revision so that stale writes are rejected.

The original manifest placement remains available through Reset this placement.
The selected fit, marked reference previews and comparison preview are retained
in [`evidence/marked-splat-alignment`](../evidence/marked-splat-alignment).
Source images and Gaussian assets remain unchanged; no missing surfaces are
generated by this operation.

Validation scope: deterministic reproduction, editor matrix conversion,
preservation/persistence of the two-section project, and actual browser renders
with both separate-section toggles. Budget: one discovery and one final pass;
no retraining or editor rebuild is needed.
